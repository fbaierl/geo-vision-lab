RAG
Context Grading

Before the LLM generates an answer, a small model evaluates each retrieved document for relevance to your query. Irrelevant documents are filtered out, reducing noise and hallucination. Significantly improves answer quality when the vector search returns mixed results.
Re-ranking (BGE)

After initial retrieval, a cross-encoder model (BAAI/bge-reranker-v2-m3) re-scores all candidate documents by jointly encoding the query and each document together. This captures semantic relevance far better than vector similarity alone. The top 3 results are kept for context.
